# Monitor Naive

![Monitor Naive 主题首页预览](preview.png?v=2)

把 [lyimoexiao/komari-theme-naive](https://github.com/lyimoexiao/komari-theme-naive) 移植到极简探针（[Monitor](https://github.com/monitor-probe/monitor)）的主题：沿用 Naive UI 的克制绿调与细边框，卡片 / 列表双视图，深浅两套主色。站点设置全部存在 hub 里，访客端不落副本。

## 主要功能

- **卡片与列表双视图**：卡片三档密度（compact / comfortable / spacious）；列表的显示列、列宽、列内外边距、行高、列间距都可配，窄屏自动单列。
- **节点卡片**：在线状态、地区旗帜、系统与内核、运行时间，CPU / 内存 / 硬盘 / 流量按配置展示（不需要的指标可以去掉，不留空位），进度条可一行一列或一行两列。
- **数据总览**：首页顶部五张卡片——当前时间、在线节点、点亮区域、流量总览、网络速率，数值跟着分组标签走。
- **节点详情**：硬件、系统与存储信息，外加两块页签——**负载**（CPU 与负载、RAM 与 Swap、磁盘、上下行、TCP / UDP、进程数六张图）与**延迟**（多条探测线路的延迟曲线与丢包率），每块都能切实时 / 历史，历史档位按 hub 的保留时间给（4 小时 ~ 30 天）。
- **延迟弹窗**：卡片和列表上的延迟按钮直接打开弹窗看曲线，不必跳详情页。
- **主题外观**：亮色 / 暗色 / 跟随系统，深浅各一套主色调，字体、数字字体、圆角、页面宽度均可配。
- **公告**：首页顶部一条公告，五种类型，内容支持简单 Markdown。
- **自定义背景**：图片或视频背景，背景模糊与卡片毛玻璃半径独立可调。
- **显示口径**：运行时间精度（天 / 小时 / 分钟 / 秒）与各字节单位的小数位数（`-1` 表示不显示该单位）都能改。

## 安装

在后台「主题」→「上传主题包」里上传 [Releases](https://github.com/akanotanin/monitor-theme-naive/releases) 中的 `theme.tar.gz` 并启用；之后可在主题卡片上点「更新」拉取最新 Release。

## 主题设置

后台「主题」→「主题设置」。所有项都存在 hub 的站点配置里，改完对访客立即生效：

| 分组         | 设置项                 | 默认                                                   | 说明                                                                                            |
| ------------ | ---------------------- | ------------------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| 运行与访问   | 数据更新间隔           | `3`                                                    | 实时数据刷新间隔（秒，1–60）                                                                    |
|              | RPC 连接模式           | `websocket`                                            | 优先 websocket，连不上可改 http                                                                 |
|              | 默认视图               | `card`                                                 | 访客首次打开首页时的节点视图                                                                    |
|              | 未登录状态显示登录按钮 | `开`                                                   | 关掉后未登录访客看不到登录入口                                                                  |
|              | 显示延迟图表按钮       | `开`                                                   | 卡片与列表上那颗查看延迟曲线的按钮                                                              |
|              | 单分组时隐藏 Tab       | `开`                                                   | 只有一个分组时不显示分组标签行                                                                  |
| 首页内容     | 显示数据总览           | `开`                                                   | 顶部五张卡片：当前时间 / 在线节点 / 点亮区域 / 流量总览 / 网络速率                              |
| 节点卡片     | 卡片尺寸               | `comfortable`                                          | compact 紧凑、comfortable 舒适、spacious 宽松                                                   |
|              | 卡片最小宽度           | `340`                                                  | 卡片自动分栏的最小宽度（px，建议 280–520）                                                      |
|              | 卡片展示指标           | cpu,memory,disk,traffic                                | JSON 数组，从 cpu / memory / disk / traffic 中挑，按固定顺序展示                                |
|              | 亮色卡片高对比度       | `关`                                                   | 亮色模式下给卡片加边框与阴影                                                                    |
|              | 卡片进度条布局         | `2col`                                                 | `1col` 一行一列、`2col` 一行两列                                                                |
|              | 标签单独一行显示       | `关`                                                   | 标签与价格常驻一行，而不是 hover 才出现                                                         |
|              | 使用 Tag 包裹运行时间  | `关`                                                   | 运行时间套一层紫色标签                                                                          |
|              | 流量统计分离颜色       | `开`                                                   | 卡片里流量统计按上行绿 / 下行蓝区分                                                             |

|              | 标签显示样式           | `tag`                                                  | `tag` 标签、`badge` 徽章                                                                        |
|              | 列间距                 | `12px`                                                 | 如 `12px`、`1rem`                                                                               |

|              | 列宽度配置             | 见下                                                   | JSON 对象，键为列名，值为 CSS 宽度                                                              |

默认的列宽度（「列宽度配置」）：

```json
{ "status": "76px", "region": "32px", "name": "minmax(200px, 1fr)", "uptime": "minmax(180px, 0.6fr)", "rate": "minmax(160px, 0.6fr)", "os": "120px", "cpu": "180px", "mem": "180px", "disk": "180px", "traffic": "180px" }
```
